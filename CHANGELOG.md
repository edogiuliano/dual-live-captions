# Changelog

## 0.0.1

Primera versión pública del proyecto.

- Captura local de audio de Windows y micrófono opcional.
- Transcripción EN/ES, parciales corregibles y texto confirmado.
- Overlays unidos o separados, movimiento y resize desde bordes/esquinas.
- Personalización por idioma, scroll, historial opcional y exportación.
- Distribución portable para Windows x64 y construcción reproducible.

Las notas de los prototipos están en [docs/archive](docs/archive/README.md).
